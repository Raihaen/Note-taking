# This a super basic note taking app

The only reason I made this was to eliminate distractions and allow me to take my notes in peace.
You can view ```.md``` files (text & math for now) and edit them, that is all!
This app allows you to edit docs using github.
You can add a custom command to your linux or wsl system for quick access.

Update 1 : Added buttons to add/rename files/folders (local hosting).
Update 2 : You now can now use it to edit docs on github ! I personally now keep all my notes on repos and edit directly from anywhere ! **Make sure you have an environment variable that allows access to your private repos ! Else you'll only be able to access view mode for public repos.** (check code for more info).
           You don't need to set up git for your system, the key will be suficient.
           
Upcoming update : browser authorization (instead of env var) & host online.
